# 体験方針：原本と作業用バインダー

更新: 2026-11-14。ユーザーとの仕様整理による目標仕様。同日に実装し、ローカル確認待ち（[session-handoff.md](session-handoff.md)）。
作業状態は [session-handoff.md](session-handoff.md)、計算は [neural-model.md](neural-model.md)、実装予定は [roadmap.md](roadmap.md) を参照する。
決定事項をつなぐデータ・処理・保存・画面の設計案は [implementation-design.md](implementation-design.md) を参照する。

## 目的と判断基準

LLMが学び、返事を考える過程を、キャラクターの仕事として理解できるゲームにする。「何の情報を持ち、何を参照し、何を書き換えたか」を動きから伝える。

自己回帰Transformer型LLMの実際の学習・推論を基準にする。「1文字の練習から複数文字の方式へ進級する」独自の学習段階は作らない。トークン列での次トークン予測と、その反復による生成を説明する。現モデルの文字単位・小さな構成と一般のLLMとの差は [neural-model.md](neural-model.md) で区別する。

1. 情報の出所と行き先を追える。文字カードからページへ変わっても、文字と順序の対応を失わない。
2. 作業用バインダーには、次の仕事に必要な元情報と現在の情報を載せる。保持範囲は実際の計算から決める。
3. 棚の原本は学習で覚えるパラメータ。推論では変えず、学習時に書き直す。
4. 運ぶ→机へ置く／装置へ渡す→開く・写す・書き直す→結果を受け取る→次へ運ぶ、という連続した動きを見せる。
5. 束やページをまとめて扱う。カード1枚ずつの配置、数1個ずつの杖操作はしない。
6. 数値は必要なときに確認する。アニメーション中は本・ページ・表紙のアイコンを中心にする。
7. 説明は物の役割から始める。その数が何に対応し、何に使われるかまで説明する。

会話中の「コロ」と既存の「コト」は同じキャラクターとして扱う。今回は名称変更を含めない。

## 物と情報の対応

机の観察ノートと勉強用の本は別の入口にする。まとまり探し・構成選択・教材・保存の条件は [model-settings.md](model-settings.md) に集約する。以下の動きと説明も、保存された構成・語彙に合わせる。

| 物 | 意味と扱い |
| --- | --- |
| ポストのことば | 入力。取り出し口からカードを手元へ引き出す。壁・支柱を通り抜けさせない |
| 文字カード | 文字または話者・区切りの目印。並べる段階ではカードのまま、①の装置でページへ変換する |
| 棚の原本 | 学習で調整・保存するパラメータ。推論では原本を持ち出さず必要な内容を写す |
| 作業用バインダー | 今回の計算に必要な情報。机で開き、現在の情報を書き直して持ち歩く。必要な元ページは保持する |
| 書き直された原本 | 学習で更新されたパラメータ。机で書き直して棚へ戻す |
| 候補と抽選 | 計算結果から次の文字の点・確率を作り、抽選する |

表紙は役割のアイコンだけを基本とし、長い説明文は載せない。文字の対応はページの見出しなどで保つ。複数文字を合わせた結果を特定の1文字の情報と偽って表示しない。

## 推論：返事を考える流れ

1. ポストの取り出し口からカードを手元へ取り出す。入力の元のことばはポストに残す。
2. 並べる部屋で、運んだ分を順序を保って一度に広げる。入りきらなければ先の札を端へ詰めて束にし、続きを広げる。
3. ①「数にする」の装置へカードをまとめて入れる。文字の見出しと数の組を持つページとして同じ順序で出し、作業用バインダーへ綴じる。不要になったカードはページへ変換される。突然消さない。
4. ①で文字に対応する数を原本から写し、順番の情報を加える。次元数をdとすると、d個とd個の対応する成分を足してd個になる。初期構成なら48個であり、連結して96個にする意味ではない。
5. 各部屋で原本を参照し、バインダーを机へ置いて現在の情報を書き直す。先の計算で必要な元情報は残す。原本は変わらない。
6. 候補・確率を作りルーレットへ進む。選ばれた文字を返事と次の計算の文脈へ加える。

すべての入力カードについて、その情報がどのページへ移ったかを追えること。文脈窓外の情報まで計算に使っているようには見せない。保持している情報と現在の計算対象は、本を開いたときに区別する。

## 学習：原本を書き直す流れ

1. お手本の途中までで、推論と同じ順方向の計算により次の文字を予想する。
2. 予想をお手本の正解と比べ、ずれを計算する。
3. 計算を逆順にたどり、各パラメータの調整量を求める。
4. 調整結果に従い机上の原本へ書き込み、棚へ戻す。

正解を予想の入力へ先に混ぜない。会話をそのまま原本へ貯める演出にしない。更新前後は実トレースを使い、複数更新をまとめる場合は閲覧時に表示単位を説明する。

## 机上の動きと表示

- キャラクターは机の前に来て仕事に立ち会う。杖は廃止し、机上の処理は自動で進んでよい。机・道具へのめり込みを避ける。
- 机に置く、開く、ページへ書き写す／書き直す、閉じて受け取る動きを見せる。
- 学習では何の文字を調整しているかを見出しで示す。共通の重みに無関係な文字名を付けない。
- 黒い説明札、数値の前後表示、式、プラス／マイナスの凡例は常設しない。
- 袋・容器で混ぜる案は取り下げ。本・バインダーへ写す／書き直す表現を採用する。

## アイテム欄・本棚・中身

- 画面右下の「今持っているもの」欄から中身を開く。キャラクターの横の持ち物表示を置き換える。スマホでも他の操作を隠さない。
- 作業用バインダーはアイテムのクリック／タップ、原本は本棚のクリック／タップで開く。
- 最初に「この本は何のための本か」を短く説明する。
- バインダーは見開きで「元の情報」と「現在の情報」を比較する。元は直前の工程ではなく、①で数へ変換した際の情報など、後の仕事に必要な基準情報。埋め込み・順番・合成結果を区別して保持する。
- 元と現在が1文字ずつ対応しない場合、入力の文字群と結果の関係を示す。存在しない1対1の対応を作らない。
- 具体的な数値は、パラメータの箱などへのマウスオーバー／タップで表示する。
- 閲覧中は一時停止。閉じたら以前の状態へ戻す。手動停止や「つぎへ」待ちから勝手に再生しない。

## 入室時の説明

入室→一時停止して中央で説明→つぎへ→本・バインダーの作業、を基本とする。同じ部屋で数1個ごとには止めない。「説明なし」も維持する。

説明する順序は「本の役割」「数の対応と用途」「今から写す／計算する／書き直す内容」。

①の例：

> 文字の本には、文字ごとに48個の数がひと組で記録されています。この組は、次のまとまりを考える計算に使うものです。受け取った文字に対応する組を、作業用バインダーへ写します。さらに、文字の順番を表す情報も加えます。

上の48は初期構成の例。実際の説明は保存された次元数に合わせる。まとまりを登録した後は文字とまとまりの両方が対象になる。

各数値、学習による変化、各成分に「色」「感情」などの決まった意味を人が割り当てているわけではないことは、本を開いたときに補足する。初期値が存在することを「学習済み」と説明しない。
初見の文字は、元の文字を見出しに残して新しい番号と原本の欄を追加する。文字登録と、正解から数値を学習することを区別する。話者・区切りの目印も普通の文字と区別する。

## チップの廃止

チップの選択・付け替え、チップ画面・専用作業台、方式を選ばせる導線を廃止する。ニューラル方式を体験の本筋とし、旧実験用集計方式やその互換保存を維持するためのUIは残さない。
ユーザーは未公開段階として、廃止に伴う旧データの消去を了承済み。旧セーブの移行・互換維持は必須にしない。これは実装再開時の整理方針であり、書類整理中にデータやコードを消去する指示ではない。
計算処理の分離は維持できるが、ユーザー向けのチップという概念は不要。温度など既存のチップに付随する設定の存廃は、整理事項として別途扱う。

## 維持する境界と精査事項

- 広い3Dの頭の中、部屋・廊下・ドア、自由視点と追従、家の散歩、絵を中心とした場面転換を維持する。自由視点では勝手にズームしない。
- 並べる部屋・①〜⑥・ルーレット・返事の9室を基本とする。旧2室は空き部屋。チップ専用の部屋・作業台は廃止対象。
- 抽選は実際の確率とトレースの乱数を使い、演出中に引き直さない。
- モデルとUIは分離する。表示専用の別モデルや架空の値を作らず、必要な情報は実際の計算トレースへ追加する。
- 文脈窓・次元・層・ヘッドは保存された構成に従い、見た目の都合で変えない。24トークン・12次元は旧実装の値で、今後の固定要件ではない。MLP幅やヘッドごとの次元も実際の計算に合わせる。
- 素材は既存のBlender中心の制作方針を維持する。

精査対象は、文脈窓外のページの保管、残差計算で参照する元情報、各位置と混合結果の対応、学習時の実更新と筆記アニメーションの集約単位、閲覧中の停止状態である。技術的に決まる部分は実計算に沿って整理し、見せ方の確認が必要なら一問一答で行う。

現在の作業許可と実装状態は [session-handoff.md](session-handoff.md) を参照する。

2026-11-14 の見せ方の更新：札・バインダーは受け渡しの際にふわっと移動し、歩行中は右下の持ち物で示す。常設の吹き出しは置かない。原本は書き始める前に棚から取り出し、作業後に戻す。机と棚へ同時に同じ本を置かない。ルーレットは⑥の結果をボックスへ投入したあとに作成し、周囲には決定した札だけを表示する。
