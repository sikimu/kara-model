# 体験の軸と3Dの頭の中

更新: 2026-11-14。今回のユーザーとの合意。従来の2D固定画面という方針より優先する。

## コンセプト

LLMがどのように作られ、学び、使われるかを、コトがかわいく働く姿として眺められるゲーム。
会話の賢さだけを目的にしない。実際の計算とキャラクターの動きを対応させる。

## 確定した体験

- 頭の中は広い3D空間。処理が増えたら場所を増やす。1画面に無理に収めない。
- 神視点で自由に回転・移動・拡大縮小でき、コトを追う視点にも戻せる。
- PC: 左ドラッグ回転、右ドラッグ平行移動、ホイール拡大縮小。タッチ: 1本指回転、2本指移動・拡大縮小。
- ことばは玄関のポストに届く。元のことばはポストに残し、写しを並べる机へ運ぶ。カバンは使わず、持っている札を手元と画面の持ち物表示に残す。置いた札だけ持ち物から消す。
- コトが作業台を操作し、計算結果を次へつなぐ。色のマスや抽象的な説明文だけで済ませない。
- 11室の建物のうち、9室で作業する（ならべる、①〜⑥、ルーレット、へんじ）。旧「とどいたことば」と「こうほ」は机・看板のない空き部屋として残す。作業室には壁・窓・棚・明かり・看板・ドアがある。コトはドアを開けて廊下を歩く。屋根と手前の高い壁は省き、中を見せる。
- 机の上は実データで計算を見せる。①④は足す、②は前のことばをどれくらい参考にするか決める、③はその割合で情報を集める、⑤は覚えた数で組み合わせ直す、⑥は続きの候補に点をつける。候補をルーレットへ直接置き、点を確率の幅に直してから抽選する。
- 数を表す棒には、その数を書いた札（+0.12 / −0.08）を立てる。金色はプラス、青はマイナス、高さは大きさ。凡例といまの式（0.11 ＋ 0.02 ＝ 0.12 など）を机の手前に出す。色の四角だけで意味を伝えようとしない。
- 学習は、6 つの部屋の重みを1個ずつ、今の値を見る→増やす／減らす→変更後を確かめる順に見せ、空き地の掲示板に「はずれの大きさ」と「次の文字が当たる確率」を 1 周ごとに記す。
- コトは机の奥に立ってこちらを向く。作業中は顔・手・机上が見えるよう手前から寄る。腕は伸ばさず、長い柄の道具で机の上のものを動かす。自由視点では自動ズームしない。
- 札はまとめて手に持って運ぶ（1枚ずつ部屋を往復しない）。並べる机に着いたら、聞いた順の番号へ1枚ずつ置く。文字の札と話者・区切りの札はそれぞれ役割を説明する。歩く時間は道のりに合わせる。
- 配置は1手順の速さ。25枚目から同じ場所に重ね、学習で並べた札を会話ごと・24枚ごとに全消去しない。杖の先端はカードの端に接触させ、貫通させない。
- 廊下の分岐では絨毯の縦横を重ねず、交差部分は横の帯だけで覆う。
- 床・机・壁・敷物・芝には、その場で描いた模様（木目、しっくい、織物、芝）を貼る。画像ファイルは置かない。重い端末では解像度と影を自動で軽くする。
- 説明の基本は「動く→一時停止して画面中央で説明→つぎへ→また動く」。左下の説明欄は使わず、動作中は説明を隠す。札1枚・計算1手・重み1個の前後で区切る。「止めて説明／説明なし」を切り替え、選択を保存する。
- LLMの知識を前提にせず、作業の目的を短い本文と図解で説明する。重要語はクリックで例つきの追加説明を開く。専門用語と実数値は折りたたむ。未習の文字は元表記と未習印を見せ、その意味も説明する。
- 場面転換は絵と行き先の木札を中心にする。ドラッグ等の操作文は小さな案内帳から必要なときだけ開く。
- 抽選の部屋にはルーレット盤を置く。全候補の実際の確率に応じた区間を描き、推論トレースの乱数で針を止める。演出中の再抽選はしない。コトが盤を動かし、結果の札を返事へ運ぶ。
- 不要な常設コピー（ことばの旅／思い出して、運んで、おぼえる／小さなTransformer）は置かない。場所や数値を特定する短い表示は残す。
- 家は家具のサイズを保って床の余白を広げ、待機中にコトが散歩する。操作開始時は散歩を止める。
- 家の幅は8.6へ拡張。家具と対応する立ち位置を外側へ移し、中央の散歩範囲も広げる。
- 丸いキャラクターの雰囲気を保ち、曲面の分割、ベベル、法線、影を改善する。ポリゴン数だけ増やして重くしない。

## 実装の境界

モデルはUIから独立。トレースに実際のattention、各計算段のベクトル、学習前後の重みの抜粋を渡す。
3Dの札・棒はデータ表示。コト、机、家具はBlender製アセットを利用する。
入力の表示文字と内部の未知語IDを混同しない。文字トークン方式は維持する。

現在の作業台は6か所。埋め込みと位置、正規化とQKV、注意の合成、投影と残差、MLP、出力を順に表示する。
学習の表示は1周分の重み更新を抜粋して補間する。全パラメータ・全学習位置の個別更新を逐一再生するものではない。
学習前後の同じ問題の予測確率を見せ、⑥から①へ赤い粒を運ぶ。赤い粒は誤差が逆向きに伝わる概念の演出で、勾配の実数値ではない。見本の1 − 正解の確率と、掲示板の平均交差エントロピーは区別する。
今後、学習位置ごとの予測と正解の比較、誤差の逆伝播、全パラメータの詳細を拡張する際も、実トレースを追加して対応させる。
旧集計方式の2D地図は実験用として維持する。
