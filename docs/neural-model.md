# 小さなニューラル言語モデル

2026-11-14のユーザー依頼で追加。チップは学習・推論の方式を表す。LLMで使われる仕組みと、比較実験用の独自・単純化方式を画面で区別する。

## ニューラル方式

- decoder-only Transformerを小さくした構成。1層・1ヘッド、埋め込み12次元、MLP24次元、文脈窓24トークン。
- 文字トークンに学習可能な位置埋め込みを加算。固定スケールのRMSNorm → scaled dot-product自己注意 → 残差 → RMSNorm → GELU MLP → 残差 → 出力射影 → softmax。
- 各位置の手前までの接頭辞だけで次トークンを予測する。未来のトークンを見ない。単層なので各接頭辞の最後のqueryだけを計算する実装でも、全位置に因果マスクをかける計算と同じ予測を得る。
- 会話は開始・話者・ターン末尾・会話末尾を含めた系列にする。発言を独立の文へ分解せず、話者交代をまたいで学習する。4人まで識別。ユーザーとコトの対話はuser/assistantに対応する。
- 次トークンの交差エントロピーを解析的に逆伝播し、SGD（学習率0.035、全体勾配ノルム1でクリップ）で全重みを更新。睡眠1回で12epoch。UIはepoch間にイベントループへ処理を返す。
- 推論はユーザー入力を文脈に入れ、assistantの続きを生成する。話者記号は出力候補から除き、ターン末尾／会話末尾を終了候補へまとめて再正規化。最大30文字。
- 語彙は聞いて学習するときに追加。未知の入力文字はunkへ。重み・語彙・更新回数・乱数状態を保存。
- 注意係数、予測確率、各epochの平均損失・勾配ノルム・更新回数・重み行列の抜粋を実測値から表示。損失は訓練損失で、汎化性能の評価ではない。

巨大な事前学習済みLLMではない。ユーザーが聞かせた小さなデータだけで学ぶため、意味の通る返事や一般知識は保証しない。文字単位は実装済み。単語・BPE方式は未実装であり、選択肢として見せない。

## チップと互換性

切り方、文脈、予測、サンプリング、学び方の5スロット。現状、文脈・予測・学習は互換のある3枚をセットで交換する。方式名を付けただけの未実装チップは作らない。

以前の直前1文字・集計表・数えて加算は「実験用の集計モデル」として保持する。この方式は会話を保存できるが、学習は発言ごとの隣接文字集計であり、相手の入力から応答を学ぶニューラル方式とは異なる。

旧セーブは実験用の選択と集計表を維持。工房の予測などのスロットからTransformerへ切り替えられる。双方の学習済み中身を別々に保存し、切り替えで消さない。短期記憶の旧文字列は話者unknownの1発言へ移行する。

## 検証

`node tools/check-neural.mjs`: 全パラメータ群で解析勾配と中心差分を照合。訓練損失低下、入力による予測変化、文脈窓外の遮断、確率正規化、重み保存復元、話者・発言順、20対話単位での忘却、旧セーブ互換を検証する。

`node tools/check-model.mjs`: 実験用モデルと温度サンプリングの既存検証。

`node tools/check.mjs` / `--mobile`: 実操作で初日進行、ニューラル学習、チップ工房、モデル切替、推論・学習中の一回スキップ、保存を検証する。
