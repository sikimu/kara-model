# セッション引き継ぎ

更新: 2026-11-14。体験方針は `docs/experience.md`、計算仕様は `docs/neural-model.md`。

## 確定した方針
- まずローカルで見た目と動きを調整する。ユーザー確認前に push・公開しない。
- LLMを全く知らない人に通じる、短い説明と図解を出す。重要語を押すと例つきの説明が開く。専門用語・実数値は折りたたむ。
- 動く→中央で止めて説明→「つぎへ」。通常の配置は1手順の速度。説明中・用語の確認中は動かさない。
- 元のことばは玄関のポストに残し、写しを手で運ぶ。カバンは使わない。
- 並べた札は24枚ごとに消さず、机の同じ場所に重ねる。学習中は次の会話でも重ねて残す。
- 候補はルーレットへ直接配置する。点→確率の幅→抽選の順に見せる。
- 旧「とどいたことば」「こうほ」は、机と看板のない空き部屋として建物を残す。
- 場面転換は絵と行き先の木札を中心にし、見まわし操作は小さな案内帳から開く。
- 引き継ぎ情報は現在の仕様・残件・検証だけに整理し、過去の経緯はGit履歴へ。コード整理は変更箇所に絞る。

## 今回の実装
- `neural-guide.js`: 初心者向け本文、SVG図解、重要語の説明。`neural-explanation.js` の詳しい計算説明とは分離。
- 未習の文字は計算上 `<unk>` のまま。トレースに元の文字を併記し、②③では元の文字＋未習印を表示。
- 札の配置は約3倍速。杖は柄だけ伸ばし、先端の球を伸ばさずカードの端へ接触。
- ポスト・空き部屋をBlenderで生成し、GLBを更新。候補の表示位置はルーレットへ統合。
- 同じページ内で閉じて開き直した際の札の保持は継続。再読み込み後の演出状態は保存しない。
