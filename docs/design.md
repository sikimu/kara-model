# 仕様

## 1. ゲームの流れ

3 つのパートを自由に行き来する。

| パート | ユーザーの操作 | モデルの動き | 見せるもの |
|---|---|---|---|
| 会話 | 文を入力して話しかける | 推論して 1 文字ずつ返す。やり取りは短期記憶に入る | 棚を引く、確率を出す、抽選する様子 |
| 盗み聞き | 話す人数（1〜4 人）と、それぞれの言葉を設定して聞きに行かせる | 短期記憶にためるだけ。集計表は変えない | キャラクターが外の広場へ出て茂みに隠れ、人が順番に話す。聞いた文がかごに飛んでいき、あふれた分が消える様子 |
| 睡眠 | 眠らせる | 短期記憶を再生して集計表を更新し、短期記憶を空にする | 頭の中のキャラが棚の数字を書き換える様子 |

- 学習が起きるのは睡眠だけ
- 短期記憶には容量がある（初期値 5 文）。あふれたら古い文から消える
- 空の状態で話しかけると「……」を返す

## 2. 空モデルの正体

初期状態は**白紙の集計表**。「ある文脈の次にどの文字が来たか」の回数を数えるだけ。

```
集計表: 文脈キー → { 次の文字 → 回数 }
例: "お" → { "は": 3, "や": 1 }
```

- 単位は文字。辞書や形態素解析は使わない
- 特別な記号を 2 つ持つ
  - 話者交代 `▶`: 発話の先頭に置く
  - 文末 `■`: 発話の終わりに置く
- 「おはよう」という発話は `▶ お は よ う ■` として扱う

### 推論（初期チップ構成）

1. 文脈を `▶` にする
2. 集計表から文脈の行を引く。行がなければ「……」で終了
3. 回数を確率に直す
4. 選び方チップで 1 文字選ぶ
5. `■` が出たら終了。それ以外は出力して、その文字を次の文脈にして 2 へ
6. 最大 30 文字で打ち切る

初期構成は直前 1 文字しか見ないので、返事は相手の発話内容に左右されない。
これは意図した制約で、「文脈の見方」チップを足す動機になる。

### 学習（初期チップ構成）

短期記憶の文を 1 つずつ再生し、隣り合う 2 文字ごとに集計表の回数を +1 する。

## 3. チップ

推論と学習を 5 つの差し込み口に分ける。各差し込み口には 1 枚だけ挿せる。

| 差し込み口 | id | 役割 | 初期チップ |
|---|---|---|---|
| 切り方 | tokenizer | 文を単位に切る | 文字単位 |
| 文脈の見方 | context | これまでの並びから文脈キーを作る | 直前 1 文字 |
| 予測 | predictor | 文脈キーから候補と回数を出す | 集計表 |
| 選び方 | sampler | 候補から 1 つ選ぶ | 回数に比例した抽選 |
| 学習 | learner | 短期記憶から予測の中身を更新する | 数えて +1 |

### チップの形

```js
export default {
  id: 'sampler-proportional',   // 一意
  slot: 'sampler',              // 差し込み口
  name: '回数に比例した抽選',     // 画面に出す名前
  description: '多く聞いた文字ほど選ばれやすい',
  // 差し込み口ごとの関数を 1 つ持つ（下表）
};
```

| slot | 関数 | 返すもの |
|---|---|---|
| tokenizer | `tokenize(text)` | 単位の配列 |
| context | `key(tokens)` | 文脈キー（文字列） |
| predictor | `predict(store, key)` | `[{ token, count }]`（なければ空配列） |
| sampler | `pick(candidates, random)` | 選んだ `token`（`candidates` は確率 `p` 付き） |
| learner | `learn(store, sequences, contextChip, trace)` | なし（`store` を書き換え、`trace` に記録） |

- `store` は予測の中身（初期は集計表）。セーブ対象
- `random` は 0 以上 1 未満を返す関数を外から渡す（テストで固定できるようにする）

### 追加チップの候補（今は作らない）

- 切り方: 単語の区切りを覚える、頻出ペアをまとめる
- 文脈の見方: 直前 2 文字、直前 3 文字、相手の最後の文字を含める
- 予測: 小さなニューラルネット
- 選び方: 一番多いものを選ぶ、温度、上位 k 個、オウム返し
- 学習: 忘却（減衰）、勾配降下法、短期記憶の容量拡張

## 4. トレース

モデルは計算結果と一緒に、手順の配列を返す。UI はこれを順に再生するだけ。

推論のイベント:

| type | 中身 | 演出の例 |
|---|---|---|
| `tokenize` | `tokens` | 入力文を切り分ける |
| `lookup` | `key`, `found` | 頭の中のキャラが棚へ行く |
| `probs` | `candidates: [{ token, count, p }]` | 確率バーが伸びる |
| `pick` | `token`, `r` | サイコロを振る |
| `emit` | `token` | 文字が口から出る |
| `end` | `reason`（`eos` / `empty` / `limit`） | 終了 |

学習のイベント:

| type | 中身 | 演出の例 |
|---|---|---|
| `replay` | `text` | 短期記憶の文を思い出す |
| `count` | `key`, `token`, `before`, `after` | 棚の数字を書き換える |
| `forget` | `text` | 短期記憶から消える |

- イベントは追加してよいが、UI は知らない `type` を無視する
- 演出を飛ばす場合（早送り、お出かけモード）はトレースを再生せず結果だけ使う

## 5. 画面

PC の大きな画面（横長）を基準にする。画面の大半は 3D の世界で、HTML は最小限にする。

```
┌────────────────────────────┐
│ タイトル              [速度] [設定] │
├────────────────────────────┤
│                                │
│   外の広場    │   家（頭の中の部屋）   │
│                                │
├────────────────────────────┤
│        入力（パートごと）           │
│     [会話] [盗み聞き] [睡眠]        │
└────────────────────────────┘
```

- カメラはふだん家に寄り、盗み聞きで外へ出るときだけ家と広場の全体を映す
- 設定（右上）: 音楽・効果音のオン/オフ、音量、「最初からやり直す」
- 盗み聞きでは、人は 1 人目から順番に 1 文ずつ話す（全員の文がなくなるまで繰り返す）

部屋にあるもの（すべて Blender で作る）:

| もの | 役割 | 演出 |
|---|---|---|
| キャラクター | 空モデル本人 | 歩く、跳ねる、文字を運ぶ、眠る |
| 棚 | 集計表 | 文脈の行を引きに行く |
| 黒板 | 今引いている行 | 回数と確率のバー、抽選の帯と針、学習時の数字の書き換え |
| サイコロ台 | 抽選 | サイコロを振る |
| ラッパ | 口 | 選んだ文字を運んで外へ出す |
| かご | 短期記憶 | 聞いた文が札になって積まれる。あふれると消える |
| ベッド | 睡眠 | 眠ると部屋が暗くなり、寝ぼけたまま札を棚へ運んで数字を書き換える |
| 広場・茂み・木・ベンチ | 盗み聞きの場所 | キャラクターが茂みの陰に隠れて聞く |
| 話す人（最大 4 人） | 盗み聞きの相手 | 色違いで現れ、吹き出しを出して話す |

- 立ち位置や黒板の大きさは `room.glb` の中の目印（空のオブジェクト）から読む
- キャラクターは部品（体、目、足、腕など）を名前付きで分けておき、動きは three.js 側で付ける
- 集計表は全体を出さず、今引いている行を黒板に見せる（候補が多いときは上位だけ）
- 演出の速度は切り替えられるようにする（ゆっくり、ふつう、飛ばす）
- 回数や確率などの数字は、部屋の中の札や黒板として出す

## 6. セーブ

localStorage に 1 つのキーで保存する。

```js
{
  version: 1,
  store: { ... },          // 集計表
  shortMemory: ["..."],    // 短期記憶
  chips: { tokenizer: 'id', context: 'id', predictor: 'id', sampler: 'id', learner: 'id' },
  stats: { sleeps: 0 }
}
```

- パートを切り替えるたびに保存する
- 読み込みに失敗したら空の状態で始める
- 「最初からやり直す」操作を用意する

## 7. 後で作るもの（今は作らない）

- お出かけモード: CPU の固定台本と対話させ、想定のキーワードを返せるかに挑戦する。抽選があるので複数回のうち何回成功したかで評価する
- 育てたモデルの共有: 集計表を文字列に書き出し、読み込めるようにする
- チップの入手と付け替えの画面

## 8. 音

音声ファイルは使わず、Web Audio API で合成する（`src/ui/sound.js`）。

- 音楽: 昼の曲と、睡眠中の夜の曲。短い繰り返し
- 効果音: 足音、跳ねる、札が出る、棚を引く、バーが伸びる、サイコロ、当たり、ラッパ（文字ごとに高さが変わる）、聞く、忘れる、数字の書き換え、眠る、起きる、広場の人の話し声
- 「飛ばす」のときは効果音を鳴らさない
- 設定は localStorage の別キー（`kara-model-settings`）に保存する。「最初からやり直す」では消さない
- ブラウザの決まりで、最初のクリックかキー入力のあとから音が出る
