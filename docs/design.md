# 仕様

ゲーム名は「からっぽのコト」。添える言葉は「聞いて、眠って、ことばが育つ。」。キャラクター・モデルの種別は引き続き「空モデル」と呼ぶ。

## 1. ゲームの流れ

3 つのパートを自由に行き来する。

| パート | ユーザーの操作 | モデルの動き | 見せるもの |
|---|---|---|---|
| 会話 | 文を入力して話しかける | 推論して 1 文字ずつ返す。やり取りは短期記憶に入る | 頭の中の画面で行を引き、確率を出し、抽選する様子 |
| お出掛け | 話す人数（1〜4 人）と、それぞれの言葉を設定して聞きに行かせる | 短期記憶にためるだけ。集計表は変えない | キャラクターが外の広場へ出て木陰でひと休みし、人が順番に話す。聞いた文がかごに飛んでいき、あふれた分が消える様子 |
| 睡眠 | 眠らせる | 短期記憶を再生して集計表を更新し、短期記憶を空にする | 夢の中で文字のつながりをたどり、回数を +1 する様子 |

- 学習が起きるのは睡眠だけ
- 短期記憶は20まとまり。お出掛け1回の会話、またはユーザーとコトの1往復を、話者・発言順を保った1件として残す。あふれたら古いまとまりごと消える。
- 空の状態で話しかけると「……」を返す

## 2. 空モデルの正体

初期状態は**白紙の集計表**。「ある文脈の次にどの文字が来たか」の回数を数えるだけ。

```
集計表: 文脈キー → { 次の文字 → 回数 }
例: "お" → { "は": 3, "や": 1 }
```

- 単位は文字。辞書や形態素解析は使わない
- 特別な記号を 2 つ持つ
  - 話者交代 `▶`: 発話の先頭に置く
  - 文末 `■`: 発話の終わりに置く
- 「おはよう」という発話は `▶ お は よ う ■` として扱う

### 推論（初期チップ構成）

1. 文脈を `▶` にする
2. 集計表から文脈の行を引く。行がなければ「……」で終了
3. 回数を確率に直す
4. 選び方チップで 1 文字選ぶ
5. `■` が出たら終了。それ以外は出力して、その文字を次の文脈にして 2 へ
6. 最大 30 文字で打ち切る

初期構成は直前 1 文字しか見ないので、返事は相手の発話内容に左右されない。
これは意図した制約で、「文脈の見方」チップを足す動機になる。

### 学習（初期チップ構成）

短期記憶の文を 1 つずつ再生し、隣り合う 2 文字ごとに集計表の回数を +1 する。

## 3. チップ

推論と学習を 5 つの差し込み口に分ける。各差し込み口には 1 枚だけ挿せる。

| 差し込み口 | id | 役割 | 初期チップ |
|---|---|---|---|
| 切り方 | tokenizer | 文を単位に切る | 文字単位 |
| 文脈の見方 | context | これまでの並びから文脈キーを作る | 直前 1 文字 |
| 予測 | predictor | 文脈キーから候補と回数を出す | 集計表 |
| 選び方 | sampler | 候補から 1 つ選ぶ | 回数に比例した抽選 |
| 学習 | learner | 短期記憶から予測の中身を更新する | 数えて +1 |

### チップの形

```js
export default {
  id: 'sampler-proportional',   // 一意
  slot: 'sampler',              // 差し込み口
  name: '回数に比例した抽選',     // 画面に出す名前
  description: '多く聞いた文字ほど選ばれやすい',
  // 差し込み口ごとの関数を 1 つ持つ（下表）
};
```

| slot | 関数 | 返すもの |
|---|---|---|
| tokenizer | `tokenize(text)` | 単位の配列 |
| context | `key(tokens)` | 文脈キー（文字列） |
| predictor | `predict(store, key)` | `[{ token, count }]`（なければ空配列） |
| sampler | `pick(candidates, random)` | 選んだ `token`（`candidates` は確率 `p` 付き） |
| learner | `learn(store, sequences, contextChip, trace)` | なし（`store` を書き換え、`trace` に記録） |

- `store` は予測の中身（初期は集計表）。セーブ対象
- `random` は 0 以上 1 未満を返す関数を外から渡す（テストで固定できるようにする）
- 温度チップは任意の `probabilities(candidates, temperature)` を持つ。推論で抽選前に呼び、変換後の確率をトレースと `pick` の両方に渡す。温度は 0.25〜2.0（1 で通常の比例抽選）。設定画面で付け替え、チップ ID と `options.temperature` を保存する。
- 初日の案内は `tutorial.step`（0: 会話、1: お出掛け、2: 睡眠、3: 起床後の会話、4: 完了）を保存。旧セーブにこの項目がなく、すでに学習・睡眠済みなら完了として扱う。

### 追加チップの候補（今は作らない）

- 切り方: 単語の区切りを覚える、頻出ペアをまとめる
- 文脈の見方: 直前 2 文字、直前 3 文字、相手の最後の文字を含める
- 予測: 小さなニューラルネット
- 選び方: 一番多いものを選ぶ、温度、上位 k 個、オウム返し
- 学習: 忘却（減衰）、勾配降下法、短期記憶の容量拡張

## 4. トレース

モデルは計算結果と一緒に、手順の配列を返す。`src/ui/stage.js` が演出を進め、推論と学習は `src/ui/mindview.js` の頭の中の画面で順に再生する。

推論のイベント:

| type | 中身 | 演出の例 |
|---|---|---|
| `tokenize` | `tokens` | 入力文を切り分ける |
| `lookup` | `key`, `found` | 地図の文脈を示し、文脈の見方から予測へ手順を進める |
| `probs` | `candidates: [{ token, count, p }]` | 集計表の 1 行に回数と確率のバーを出す |
| `pick` | `token`, `r` | 抽選の帯に針を動かし、選んだ文字とつながりを光らせる |
| `emit` | `token` | 地図の次の文字へ進み、「口から出る言葉」に 1 文字足す |
| `end` | `reason`（`eos` / `empty` / `limit`） | 終了の理由を出し、家に戻って返事をする |

学習のイベント（夢の中で再生）:

| type | 中身 | 演出の例 |
|---|---|---|
| `replay` | `text`, `tokens` | 思い出している文を文字の札で出し、短期記憶の該当する文を示す |
| `count` | `key`, `token`, `before`, `after` | 地図のつながりをたどり、回数の書き換えと「+1」を見せる |
| `forget` | `text` | 短期記憶から消える |

- `hear`（`text`）は聞いた文をかごに入れる。容量からあふれたときの `forget` も家と広場で見せる
- イベントは追加してよいが、UI は知らない `type` を無視する
- 演出を飛ばす場合（早送り、お出掛けモード）はトレースを再生せず結果だけ使う

## 5. 画面

PC の横長画面とスマホの縦長画面に対応する。ふだんは 3D の家だけを見せ、部屋のものを押して操作する。推論と学習では頭の中の画面（2D canvas）に切り替える。HTML は必要なときの文字入力と設定など最小限にする。

```
┌────────────────────────────┐
│ 小さなロゴ                  [設定] │
│                                │
│          家のものを押して操作         │
│                                │
│        選んだ操作の入力だけ表示        │
└────────────────────────────┘
```

- キャラクターを押すと話す入力、ドアで聞きに行く入力、ベッドで睡眠の確認が出る。黒板を押すと頭の中を見る。同じものや何もないところを押すと入力を閉じる
- 聞きに行くと、幕の切り替えで「まちの ひろば」に移り、帰ると家に戻る
- 設定（右上の歯車）: 10 段階の速度、演出を飛ばす、音楽・効果音のオン/オフ、音量、「最初からやり直す」
- 演出中は入力を隠し、一時停止・コマ送りを表示する。頭の中をのぞいているときは家に戻るボタンを出す
- お出掛けでは、人は 1 人目から順番に 1 文ずつ話す（全員の文がなくなるまで繰り返す）

### 家と広場

部屋と広場にあるもの（形は Blender で作る）:

| もの | 役割 | 演出 |
|---|---|---|
| キャラクター | 空モデル本人 | 歩く、跳ねる、考える、眠る |
| 棚 | おぼえたことのしるしとなる飾り | 本を並べる |
| 黒板 | そだちぐあい | おぼえた文字、文字のつながり、数えた回数、眠った回数を表示する |
| かご | 短期記憶 | 聞いた文が札になって積まれる。あふれると消える |
| ベッド | 睡眠 | 部屋が暗くなり、横になって眠る。夢の中で学習し、起きる |
| ランプ・窓・絵・観葉植物 | 家の飾り | 夜はランプが部屋を照らす |
| 広場・茂み・木・ベンチ | お出掛けの場所 | キャラクターが木陰でひと休みしながら聞く |
| 柵・街灯・花・石・丘・雲 | 外の風景 | 家と広場の周りを彩る |
| 話す人（最大 4 人） | お出掛けの相手 | 色違いで現れ、吹き出しを出して話す |

- 立ち位置や黒板の大きさは `room.glb` の中の目印（空のオブジェクト）から読む
- キャラクターは頭・体・耳・目・腕・足・マフラー・しっぽ・芽に分けて作る。呼吸、まばたき、頭や芽の揺れ、歩きなどの動きは `src/ui/actor.js` で付ける
- 家やキャラクター、小物には影を付ける。遠くの丘と雲は影の対象にしない
- サイコロ台とラッパは置かない。抽選と出力は頭の中の画面で見せる
- 演出の速度は設定で 10 段階に切り替えられる。「演出を飛ばす」も選べる
- 会話では聞いた言葉と返事をキャラクターのそばの札に出し、短期記憶に入るときにかごへ飛ばす

### 頭の中の画面

`src/ui/mindview.js` が 3D の世界の上に重ねた 2D canvas に描く。キャラクターの頭から小さな泡が出て、雲が画面いっぱいに広がる「もわもわ」で切り替える。終わると雲が縮んで家に戻る。

| 表示 | 内容 |
|---|---|
| 文字のつながりの地図 | 集計表の全体。文字を点、次の文字へのつながりを線で表し、今たどっている場所を示す |
| いまの手順 | 5 つの差し込み口と、いま使っているチップの名前・説明 |
| 集計表の 1 行 | 文脈の次に来る文字、回数、確率のバー |
| 抽選 | 全候補を確率に比例した幅の帯に並べ、乱数の位置に針を動かす |
| 口から出る言葉 | 推論で選んだ文字を順に並べ、終了の理由を示す |
| 短期記憶 | 学習中・地図をのぞいているときに、覚えている文と容量を示す |
| 育ち具合 | おぼえた文字、つながり、数えた回数、眠った回数 |

- 集計表の 1 行は回数の多い順に、画面に収まる数を出す。選んだ文字が隠れるときは最後の行と入れ替え、残りの文字数も示す
- 学習時は「夢の中」として、思い出している文と隣り合う文字を示す。抽選の代わりに回数の書き換え（変更前 → 変更後）と「+1」を見せ、地図のつながりを更新する
- 黒板を押すと地図をのぞける。文字をクリック・タップするとその行が出て、「家にもどる」で閉じる
- 幅 640px 以下では地図と計算内容を縦に並べる。収まらない分はスクロールして読み、家に戻るとスクロール位置を戻す

## 6. セーブ

localStorage に 1 つのキーで保存する。

```js
{
  version: 1,
  store: { ... },          // 集計表
  shortMemory: ["..."],    // 短期記憶
  chips: { tokenizer: 'id', context: 'id', predictor: 'id', sampler: 'id', learner: 'id' },
  stats: { sleeps: 0 }
}
```

- パートを切り替えるたびに保存する
- 読み込みに失敗したら空の状態で始める
- 「最初からやり直す」操作を用意する

## 8. 音

音声ファイルは使わず、Web Audio API で合成する（`src/ui/sound.js`）。

- 音楽: 昼の曲と、睡眠中の夜の曲。短い繰り返し
- 効果音: 足音、跳ねる、札が出る、棚を引く、バーが伸びる、サイコロ、当たり、ラッパ（文字ごとに高さが変わる）、聞く、忘れる、数字の書き換え、眠る、起きる、広場の人の話し声
- 「飛ばす」のときは効果音を鳴らさない
- 設定は localStorage の別キー（`kara-model-settings`）に保存する。「最初からやり直す」では消さない
- ブラウザの決まりで、最初のクリックかキー入力のあとから音が出る
